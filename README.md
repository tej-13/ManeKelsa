# Mane-Kelsa (ಮನೆ ಕೆಲಸ) 🏠

Hyper-Local Work Directory Android App for domestic workers in small towns.

## Problem Statement
Domestic workers find work only through word of mouth and lose income
when their regular employer is away. Mane-Kelsa solves this with a
Digital Local Job Board.

## Features
- 👷 Worker profiles with name, skill, daily rate
- ✅ Real-time availability toggle
- 📞 One-tap direct calling
- 👍 Thumbs Up rating system
- 🌍 Kannada language UI
- 🔥 Firebase Firestore real-time sync

## Tech Stack
- Kotlin + Jetpack Compose
- Firebase Cloud Firestore
- Compose Navigation
- Android Min SDK 24
